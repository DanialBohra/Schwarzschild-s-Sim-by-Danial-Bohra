# Schwarzschild-s-Sim-by-Danial-Bohra
I made a sim that models Black Holes!!!!


This is version 1.0

written entirely in java script, CSS and HTML wrapper using  calculations from General relativity.

- Models Kerr rotating Black holes
- Includes relativistic doppler beaming with sound
- models orbiting light and massive bodies
- orbit trails are modelled along geodesics
- curvature influences optical view distortion from gravitational lensing
- Frame dragging is modelled for the ergosphere
- Togglable settings for accretion disk/rate, Polar jets, Radius, Mass, spin
- Gravitational well is plotted automatically
- Hawking radiation, Time dilation,Isco radius, and Schwarzschild radius are all modelled.
- more to come!
